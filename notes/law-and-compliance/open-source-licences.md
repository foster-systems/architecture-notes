    author: Open Source Initiative
    url: "https://opensource.org/licenses"
    type: docs
    year: 2026
    note: "The Open Source Initiative's list of licences it has approved as meeting the Open Source Definition. Each entry gives the licence text, its SPDX identifier and a category such as popular, superseded or special purpose. A licence missing from the list, such as the SSPL or the Business Source License, is not open source in the OSI's sense."
  - title: Licenses appendix

    year: 2026
    note: "A table comparing common licences on what they permit, require and limit. Its columns include patent use, disclosing source, keeping the same licence and whether network use counts as distribution. It is part of choosealicense.com, a site GitHub runs to help projects pick a licence."
  - title: Licenses
    author: Google Open Source
    url: "https://opensource.google/documentation/reference/thirdparty/licenses"
    type: docs
    year: 2026
    note: "A public mirror of part of Google's internal documentation on using third-party code. It sorts licences by their obligations into categories such as restricted (for example the GPL), reciprocal, notice and permissive. It bans the AGPL, the OSL, the SSPL and the Business Source License outright."
  - title: GNU Affero General Public License version 3
    author: Free Software Foundation
    url: "https://opensource.org/license/agpl-v3"
    type: docs
    year: 2007
    note: "The full text of the AGPL, published by the Free Software Foundation and hosted by the Open Source Initiative. It differs from GPLv3 mainly in section 13: users who interact with a modified version over a network must be offered its source code. That section is what makes the AGPL reach software offered as a service."
  - title: "ISO/IEC 5230: open source license compliance"

    url: "https://openchainproject.org/license-compliance"
    type: spec
    year: 2020
    note: "The OpenChain Project's page on ISO/IEC 5230:2020, an international standard for the key requirements of an open source licence compliance programme. The OpenChain text is free to review and adopt, and functionally identical to the ISO version. A company can adopt it by self-certification."
